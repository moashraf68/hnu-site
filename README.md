# أسرة طلاب من أجل مصر — جامعة حلوان الأهلية
### Students For Egypt — Helwan National University (HNU)
**Official Portal, Website & Management System (Full-Stack & Static)**

---

## 🌟 نظرة عامة على المشروع (Project Overview)

يحتوي هذا المستودع على الكود المصدري الكامل للموقع الرسمي وبوابة الخدمات الإلكترونية المركزية لأسرة **«طلاب من أجل مصر» — جامعة حلوان الأهلية**.

المشروع مبني بهيكلية متكاملة تضم نسختين:
1. **`hnu-central/`**: النسخة المتكاملة **Full-Stack** المبنية بأحدث تقنيات الويب الحديثة (Next.js 14, TypeScript, Prisma ORM, PostgreSQL, Server Auth, REST APIs).
2. **`hnu-site/`**: النسخة الخفيفة **Static SPA** التي تعمل حالياً كنسخة إنتاج سريعة منشورة على Vercel عبر الرابط: [https://hnu-site-chi.vercel.app](https://hnu-site-chi.vercel.app).

```text

│   │   └── api/              # الباك إند وواجهات البرمجة الخلفية (REST API Routes):
│   │       ├── auth/         # مسارات تسجيل الدخول، إنشاء الحساب، وتسجيل الخروج
│   │       ├── admin/        # إدارة الطلاب، رصد التقييمات، إحصائيات النظام، وإدارة الفعاليات

│   │       ├── profile/      # تحديث بيانات الطالب، تغيير كلمة المرور، ورفع الصورة

│   ├── components/           # مكونات الواجهة (Navbars, Footers, QRScanner, AdminSidebars)
│   ├── config/               # ملف الإعدادات الموحد للبيانات (site.ts)
│   ├── lib/                  # مكتبات السيرفر والباك إند (auth.ts, db.ts, cloudinary.ts, utils.ts)
│   ├── prisma/               # مخطط قاعدة البيانات العلائقية (schema.prisma)

    ├── index.html            # واجهة الصفحة الواحدة
    ├── script.js             # منطق التطبيق التفاعلي (Auth, QR Attendance, Archive, CSV Export)
    ├── style.css             # التصميم المتجاوب ونظام الألوان المتوافق مع الهواتف الذكية
    ├── config.js             # بيانات اللجان والقيادة والفعاليات ومعرض الصور
    ├── assets/images/        # الهوية البصرية، اللوجو، وصور اللجان والفعاليات والمعرض
    └── vercel.json           # إعدادات التوجيه والنشر على خوادم Vercel
```

## ⚡ أبرز ميزات النظام (Core Features)

- 🔐 **نظام مصادقة وأمان متكامل (Unified Auth & Security):**
  - تسجيل الدخول الموحد بالرقم القومي (14 رقماً) وكلمة المرور.
  - توجيه تلقائي للمشرفين إلى **لوحة الإدارة** وللأعضاء إلى **لوحة العضو**.
  - حماية ضد هجمات التخمين (Brute-Force Lockout) وفحص التوافق الأمني.
- 📱 **نظام الحضور الذكي بالـ QR والأرشيف المعتمد (QR Attendance & Archive):**
  - إمكانية رفع صورة كود الـ QR وتفعيلها مباشرة لتظهر لكافة الطلاب.
  - إيقاف الفعالية بضغطة زر مع أرشفة سجلات الحضور تلقائياً وإخفاء كود الـ QR فوراً.
  - **حافظة الفعاليات السابقة:** أرشيف دائم لكل فعالية مع قائمة الحضور، الكلية، والفرقة، ورقم الهاتف.
  - **تصدير إكسيل (CSV) وطباعة رسمية:** أزرار مخصصة لاستخراج كشوف الحضور وكشف أعضاء الأسرة بصيغة Excel أو ورقة طباعة رسمية جاهزة للاعتماد.
- ⭐ **نظام تقييم الأداء للأعضاء (Performance Evaluations):**
  - بحث فوري بالاسم أو الرقم القومي أو الكلية.
  - حجب تقييم حسابات الإدارة حفاظاً على دقة الصلاحيات.
  - ظهور الصور الشخصية لجميع الأعضاء لسهولة التعرف والتنظيم.
- 🎨 **تصميم واجهات احترافي ودعم كامل للهواتف (Responsive UI):**
  - دعم ثنائي اللغة (عربي / English).
  - متوافق 100% مع أجهزة Android و iPhone وشاشات سطح المكتب.

## 🛠️ التشغيل والتطوير محلياً (Local Setup)

### 1. تشغيل النسخة الكاملة (`hnu-central`):
```bash
cd hnu-central
npm install
# إعداد متغيرات البيئة في ملف .env بناءً على .env.example
npx prisma generate
npm run dev
```
افتح المتصفح على: `http://localhost:3000`

### 2. تشغيل النسخة الخفيفة (`hnu-site`):
```bash
cd hnu-site
npx serve -s . -l 3000
```
